Questions

Does it work without a TeraBox account?

Yes. Listing and streaming work anonymously. Getting a direct download link needs either a TeraBox API key or your own TeraBox account connected to this server — see docs/REQUIREMENTS.md for the one-line setup of each option.

What about links with an extraction code?

Paste the 4-character code in the second box (or add ?pwd=1234 to the link itself) and the share unlocks.

Can I use this on my phone?

Yes — the site is fully responsive and the player is touch friendly. You can also add it to your home screen; it ships as a PWA.

Is it legal to download files here?

Only use it for files you own or that the owner shared with you. Respect copyright and the rights of the original creator.
